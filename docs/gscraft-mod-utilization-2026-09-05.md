WaterMedia) were opened and `assets/<modid>/lang/en_us.json` counted for blocks (B), items (I) and entities (E), then

camp spec, the Create chapter, the interface doc, the loot sheet, the six KubeJS scripts, `server/config` and the
world serverconfigs). Ratings: **none** = no role; **low** = a few items or dressing; **medium** = one system used,

## 3. The five biggest wins

1. **`mtsconfig.json` → `generateOverrideConfigs: true`** (one line, one boot). It dumps `craftingoverrides.json` into `config/mts/`, the file capability audit §5b and crafting §5.7 left as "Phase C's in-game find"; the IV vehicle kits get their real path and the "vehicle item on completion" fallback is not needed.
2. **`/hordes SpawnHordeWave` as the wave engine** (a command per wave in the loop script). The mod's five wave tables, pathing and multiplayer scaling exist; the finale doc listed it as the backup — it is cheaper than the primary.
3. **In Control `areas.json`** (one file): named site rectangles fix the rejected `minx/maxx` keys and give the enemies §3 rules, the Woods rule and the held-site denial one `area` each; `effects.json` adds the sewers' Darkness for free.
4. **FTB Quests' own blocks and Item Filters** (a block in two templates, a filter per task): a Stage Barrier on the hangar door and the tower gate, a Quest Chest at the parts rack, and tag filters for the six "any of" hand-ins (D5, D6, J5, W14, U10, J11) the book cannot otherwise express.
5. **Antiblocks for the lit board, the Doomsday safe for the dossiers** (a palette swap in `camp.py` / `dossiers.py`): the gatehouse tier-3 "lit wall map" becomes six full-bright blocks with no power, and the dossier chest a safe that reads as one.
